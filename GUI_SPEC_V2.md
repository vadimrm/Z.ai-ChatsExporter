## 1. Баги

### BUG-1 — кракозябры в русских названиях чатов (причина найдена)

Симптом: в списке чатов русские названия отображаются кракозябрами.

Диагностика (2026-11-07, только чтение, без изменений кода):

| Проверка | Результат |
|---|---|
| движок-исходник + `PYTHONUTF8=1` | названия чистые: `'Экспорт чатов autoclaw'`, `'Инфляция в США за 100 лет'` |
| engine exe **без** `PYTHONUTF8` | кракозябры: `'M15. ������…'`, в выводе U+FFFD |
| engine exe **с** `PYTHONUTF8=1` | **всё равно кракозябры** — корень бага |

Вывод: замороженный движок (PyInstaller) **игнорирует** `PYTHONUTF8` /
`PYTHONIOENCODING` и пишет в пайп в локальной кодировке (cp1251); GUI читает
UTF-8 → кракозябры. Движок-исходник флаг слушает, поэтому смоук-тест это не
поймал, а JSON с кракозябрами остаётся валидным JSON — и тест поставки прошёл.

Исправление (зона frontend, движок не трогается): в `build/engine_shim.py`
(точка входа engine exe) перед вызовом движка переустановить кодировку потоков:
`sys.stdout/stderr.reconfigure(encoding="utf-8", errors="replace")`; пересборка
engine exe. В `test_release.py` добавить проверку содержания: в названиях есть
кириллица и нет U+FFFD (сегодня тест проверял только валидность JSON).

## 3. Ответы на ваши вопросы

**Q1 — зачем был выпадающий список «Формат» (md/txt/json) рядом с надписью «Формат».**
Он выбирал формат для кнопки «Экспортировать все»: у движка `/all` требует
ключ `/format`. С появлением чекбоксов форматов (R4) список теряет смысл —
форматов может быть несколько одновременно. Ваше «пусть запоминается между
вызовами» реализую так: сами чекбоксы MD/TXT/JSON сохраняются в конфиг и
восстанавливаются при следующем запуске. Предложение: combobox убрать совсем.
**Подтвердите.**

**Q2 — к чему относится «Лимит результата» и что такое 4000.**
Это ключ движка `/tool-limit N`. Работает только при включённом чекбоксе
«Включить инструменты»: текст результата каждого вызова инструмента
обрезается до N символов (по умолчанию 4000), вместо хвоста пишется
«… (обрезано, всего …)». Зачем: результаты бывают огромными (дампы файлов,
вывод команд), без лимита файл распухает на десятки мегабайт. Предложение:
подпись «Лимит символов результата инструментов:», поле неактивно, пока
«Включить инструменты» не отмечен.

**Q3 — кнопка папки.** Принято: поле «Папка вывода» — вниз, рядом с кнопкой;
кнопка — «Открыть папку вывода» (R12).

**Q4 — «ZCode from Z.ai»: как принято.**
По общепринятой практике копирайт указывает правообладателя-человека или
компанию; вклад инструмента принято оформлять отдельной строкой-кредитом, а
не частью копирайта. Слово «from» в таком контексте не используется — пишут
через скобки: «ZCode (Z.ai)». Варианты:
- **A (рекомендую)**: `Copyright © 2026 by Vadim Madgazin` + отдельная строка
  `GUI created with ZCode (Z.ai)`;
- **B**: одной строкой `Copyright © 2026 by Vadim Madgazin & ZCode (Z.ai)`.
Файл `LICENSE` (MIT, авторы «Vadim Madgazin, AutoClaw.Z.ai») не трогаю без
согласования — он общий с движком.

## 4. Что хорошо / что плохо (моя оценка предложений)

Хорошо:
- чекбоксы форматов гибче трёх отдельных кнопок — можно получить сразу несколько форматов за один прогон;
- мультивыбор чатов + «Выбрать всё»/«Стереть всё» — стандарт для массовых операций;
- сортировка колонок с индикатором направления — ожидаемое поведение таблицы;
- бонус: с серийными экспортами появится честный прогресс «k из N» без изменения движка;
- дефолт папки = папка приложения — предсказуемо для пользователя;
- брендинг в заголовке и кнопка сайта — нормально, реализация простая.

Риски / замечания:
- ☑-колонка в Treeview — самодельная: клик по первой ячейке строки переключает
  чекбокс, клик по остальной строке — обычное выделение. Опишу в подсказке;
- R7 при большом выборе: 60 чатов × 3 формата = 180 файлов за раз — нужен
  внятный итог («готово k, ошибок m»), делаю;
- R8 требует изменения движка (ER-2) — срок не в моей зоне, кнопка до тех пор неактивна;
- «Zcode Chats» — заглушка: чтобы не выглядело поломкой, в статусе будет
  «режим пока не поддерживается»;
- взаимодействие фильтра и выбора: предлагаю чекбокс = выбор, поиск = только
  просмотр, т.е. экспортируется всё отмеченное, даже скрытое фильтром. **Подтвердите.**
