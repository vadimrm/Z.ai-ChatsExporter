# Что нового в ver. 2.00 (по сравнению с 1.27)

Русский · [English](CHANGES.md) · [中文](CHANGES.zh.md)

С 1.27 вышло 49 промежуточных версий (18 бет и 31 RC). Ниже — главное с точки зрения пользователя.

## Безопасность данных

- **Локальные копии баз**: программа читает только свои копии (ZCodeData / AutoClawData рядом с exe); исходные базы AutoClaw/ZCode никогда не изменяются.
- **Безопасный импорт**: обновление копии идёт через SQLite backup-API — можно не закрывать AutoClaw/ZCode; перед заменой файл проверяется, при сбое всё откатывается.
- **Три резервные копии** каждой базы (вместе с -wal/-shm): `.bak1` (свежая) — `.bak3` в папках ZCodeData / AutoClawData.
- **Восстановление удалённых чатов**: пока копия не обновлена, удалённый диалог ещё виден; подробнее — в README (раздел «Удалённые чаты»).

## Работа с чатами

- **Скрытые чаты**: чекбокс «Показывать скрытые чаты»; типы `del` (удалённые), `arch`, `wfchld`, `selchat`, `auto` показываются в колонке «Тип».
- Колонка **«Ток»** — размер контекста чата; сортировка и поиск сохранены.
- Экспорт «в один файл» и по-форматная матрица опций — как раньше, но файловые блоки теперь **показываются всегда** (раньше чекбокс мог их скрыть).
- «Показать служебные файлы» (AutoClaw) — скрипты и черновики, создававшиеся агентом по ходу работы.

## Заголовок экспорта

Полная шапка в md/txt/json у обоих движков: Харнесс-ядро (версия встроенного ядра ZCode), проект, тип, сессия, каталог, даты, **«Сообщений: N / M (вопросы/ответы)»**, файлы, модели с effort, **токены**: «Контекст чата: 28 019 токенов (2.8%/1М)» (у AutoClaw — «16 161 из 1М (1.5%)»), «Автосжатие при», «Всего израсходовано»; строка и футер экспортёра. У ответов — модель-автор и время работы.

## Новый режим «актуальный контекст»

- Чекбокс **«Только актуальный контекст»** (ZCode) и кнопка-пресет **«Пресет: актуальный контекст модели»**: экспортируется то, что модель реально видит после последнего автосжатия — сводка уплотнённой истории отдельным блоком + «живой хвост» + служебные сообщения, невидимые пользователю.
- Метки границ автосжатия в обычном экспорте.

## Интерфейс

- **Все диалоги собственные** — текст в них выделяется и копируется (Ctrl+C / правый клик).
- **Копирование правым кликом из любого элемента**: поля ввода (без выделения — весь текст), строки таблицы под кликом (не выделение), заголовок таблицы (все колонки; отдельный пункт «Копировать заголовок и список чатов»), статус-строка, заголовок окна.
- Статус-строка: зелёный/жёлтый/красный; жёлтые ноты («db_profiles.cfg не найден», «Слишком длинные строки в файле…», «минимальный состав» после импорта) переживают загрузку списка; смена языка переводит статус.
- «Открыть папку экспорта»: при некорректном пути — статус «Некорректная папка экспорта» (после выбора правильной папки снимается); файловые диалоги открываются в осмысленных папках (актуально для Windows 8.1).
- Первый запуск открывается в режиме Zcode Chats.
- Иконка exe — «гусиное перо» (как у окна программы).

## Конфигурация

- **db_profiles.cfg v3**: полный список файлов каждой базы с относительными путями; версия формата проверяется при чтении; при изменении места хранения достаточно поправить текст.
- **ExportChat.cfg v7** с автоматической миграцией старых версий; строгая проверка структуры (повреждённый файл сохраняется как `.err`, создаётся заводской).
- **Защита от сверхдлинных строк**: любые строки из cfg/lang-файлов длиннее 500 символов обрезаются, имя файла показывается жёлтой нотой.
- Языковые файлы `lang_ru/en/zh.cfg` правятся текстом и перечитываются на лету.

## Прочее

- Экспорт пустых чатов (шапка без ошибки), «саму в себя» копировать нельзя (раньше могло повредить базу), ошибочный файл не прерывает серию.
- Служебные сообщения (форки, rewind) больше не «протекают» как фейковые реплики; копии контекста подписываются «Контекст».
- Три языка интерфейса и экспортов; число автоматических проверок выросло с ~230 до 633.
