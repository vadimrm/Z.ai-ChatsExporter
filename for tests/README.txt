Z.ai Chats Exporter by Vadim R.M. ver. 1.27 — проверка на другом компьютере
===============================================================================

Что здесь:
  ExportChat.exe   — окно программы (запускать его, двойной клик)
  db_profiles.cfg  — стандартные пути к базам AutoClaw/ZCode (для человека)
  README.txt       — эта инструкция

Компьютер без Python, без AutoClaw и без ZCode подходит: программе больше
ничего не нужно. Реестр и %APPDATA% НЕ используются. Настройки (ExportChat.cfg)
появятся рядом с exe после первого запуска; нет их — создаются с нуля.

Начало работы:
1. Скопируйте сюда базы чатов (при ЗАКРЫТЫХ AutoClaw/ZCode на исходной машине):
     AutoClaw:  runtime.sqlite  (и runtime.sqlite-wal / -shm, если есть)
     ZCode:     db.sqlite       (и db.sqlite-wal / -shm, если есть)
   Например, в подпапку «базы» рядом с exe.
2. Запустите ExportChat.exe.
3. Нажмите кнопку «SQL база» и укажите файл базы — список чатов загрузится
   сразу. Пути запоминаются раздельно для каждого режима.
4. Отметьте чаты (клик по строке), отметьте форматы (MD/TXT/JSON) и нажмите
   «Экспортировать выбранные чаты».

Куда пишутся файлы: в «папку экспорта» (по умолчанию — эта же папка с exe;
выбирается кнопкой «Папка экспорта»), внутри неё создаются субпапки:
«AutoClaw Chats» / «ZCode Chats» — экспорт чатов, «AutoClaw SQL» /
«ZCode SQL» — копии баз (кнопка «Экспорт SQL базы»). В режиме Zcode чаты
дополнительно раскладываются по папкам проектов.

Элементы управления (все):
- Радио «AutoClaw Chats» / «Zcode Chats» — выбор источника чатов; у каждого
  режима свой список, свой отмеченный чат и свой путь базы.
- «Язык:» — интерфейс ru/en/zh, меняется мгновенно, запоминается.
- «Поиск чата:» — фильтр таблицы по названию (скрытые фильтром чаты
  не экспортируются).
- «Обновить чаты» — перечитать список из базы (если чаты изменились,
  пока программа открыта).
- Таблица чатов: колонка ☑ — отметить для экспорта (клик по строке отмечает
  и выделяет); заголовки — сортировка ↑/↓.
- «Выбрать всё» / «Снять выбор» — отметить/снять все ВИДИМЫЕ строки.
- «Формат: MD TXT JSON» — какие форматы производить в серии экспорта.
- Матрица «Параметры экспорта» — своя колонка настроек для каждого формата:
  «Добавлять вызов инструментов» (+ «Максимальная длина, литер» — общий
  лимит, активен при любом включённом tools), «Промежуточные реплики»,
  «Показать служебные файлы» (только AutoClaw), «Скрыть блоки файлов»,
  «UTF-8 Byte Order Mark» (md/txt независимо; в JSON BOM невозможен).
- «Папка экспорта» — выбрать материнскую папку экспорта; рядом поле пути.
- «Открыть папку экспорта» — открыть её в проводнике (после экспорта —
  с выделением последнего файла).
- «SQL база» — выбрать файл базы; после выбора список грузится сразу.
- «Экспорт SQL базы» (под полем базы) — сохранить копию базы (+ -wal/-shm)
  в субпапку «… SQL».
- «Экспортировать выбранные чаты» — серия: отмеченные чаты × отмеченные
  форматы, прогресс «k из N»; ошибка одного чата не прерывает остальные.
- Чекбокс «записать в один файл» (второй ряд действий; с маленькой буквы —
  это продолжение надписи кнопки «Экспортировать выбранные чаты …»):
  выключен — каждый
  выбранный чат пишется в свой файл; включён — все ВЫБРАННЫЕ чаты пакуются
  в ОДИН файл каждого отмеченного формата (AC-ALL-/ZC-ALL-дата; внутри —
  заголовок «Выбранные диалоги …» и только выбранные чаты). Отметьте
  «Выбрать всё» — получите все чаты режима в одном файле. Без отмеченных
  чатов или форматов — красная подсказка «Отметьте хотя бы один чат и один
  формат.» (тексты ошибок и меню — на языке интерфейса, раунд 21.)
- «Donate» (правый угол ряда действий) — страница поддержки автора.
- Строка статуса внизу: сообщения и ошибки. Текст КОПИРУЕТСЯ: Ctrl+C в окне
  (или правый клик → «Копировать»); при пустом статусе Ctrl+C копирует
  заголовок окна. Окно «Ошибки экспорта» тоже с копируемым текстом.
- «Vadim R.M. - авторский сайт» — https://www.vmgames.com/

Авто-поиск базы (когда поле «SQL база» пусто): реестр не читается и по
диску не ищется; проверяются только стандартные места из файла
db_profiles.cfg, лежащего рядом с exe. Программа читает его при старте
и никогда не перезаписывает: если AutoClaw/ZCode сменит место базы,
исправьте пути в этом файле текстовым редактором (UTF-8), exe менять
не нужно. Если файл удалить — программа сообщит и запишет заводской;
если испортить — битый сохранится как db_profiles.cfg.err, а заводской
будет записан заново. Нет файла базы — ошибка «база не найдена»:
укажите файл кнопкой «SQL база».

Если появляется ошибка — скопируйте её текст (Ctrl+C) и пришлите:
без точного текста причину не найти.
