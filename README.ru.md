# Z.ai Chats Exporter by Vadim R.M. ver. 1.27

GUI-ветка проекта **AutoClaw.Z.ai-ExportChat** (материнский проект — одноимённая консольная утилита экспорта чатов AutoClaw): экспорт диалогов AutoClaw и ZCode в Markdown, TXT и JSON

Настольная программа для Windows: читает локальные базы чатов AutoClaw и ZCode и сохраняет переписку в файлы — Markdown, обычный текст или JSON. Один exe, без установки Python: адаптеры баз работают в одном процессе с окном (AGREEMENTS.md, раунд 19 — движки слились с GUI, командная строка удалена).

Неофициальный инструмент. Не связан с Z.ai, работает только с локальной базой, в сеть не ходит.

## Возможности

- два режима: **AutoClaw Chats** (runtime.sqlite) и **Zcode Chats** (db.sqlite) — у каждого свои список, выбор и путь базы;
- таблица диалогов: ☑-выбор (по умолчанию отмечен первый), сортировка по любому столбцу — клик меняет направление (▲/▼), поиск по названию;
- экспорт выбранных чатов × отмеченных форматов (MD / TXT / JSON) — N×M файлов за один прогон, с прогрессом «k из N» и сводкой ошибок; ошибка одного чата не прерывает остальные;
- чекбокс «Экспорт в один файл»: выключен — каждый выбранный чат пишется в свой файл; включён — все ВЫБРАННЫЕ чаты пакуются в один файл каждого формата (заголовок «Выбранные диалоги …», имена AC-ALL-/ZC-ALL-дата); «Выбрать всё» + чекбокс = все чаты режима в одном файле;
- поформатная матрица опций (каждый столбец настраивает свой формат): вызовы инструментов (+ общий лимит длины результата), промежуточные реплики, служебные файлы (только AutoClaw), скрытие блоков файлов, UTF-8 BOM;
- язык подписей в экспортируемых файлах — русский (по умолчанию), английский или китайский; интерфейс переключается на лету;
- база открывается только на чтение (mode=ro) — AutoClaw/ZCode можно не закрывать; при блокировке базы ZCode читается временная копия;
- файлы никогда не перезаписываются: повторный экспорт получает суффикс ` (1)`, ` (2)`…;
- имена файлов: `AC-ГГГГ-ММ-ДД-название.ext` / `ZC-ГГГГ-ММ-ДД-название.ext`; в ZCode-режиме чаты дополнительно раскладываются по папкам проектов.

## Требования

- Windows 8.1 или новее, 64-бит (работа проверена на 8.1, 10 и 11; на Windows 7 не запускается — сборка Python 3.12 эту систему не поддерживает);
- устанавливать Python не нужно;
- AutoClaw и ZCode на этой машине не обязательны: базы — обычные файлы, программа работает с их **локальными копиями** — скопируйте `runtime.sqlite` / `db.sqlite` на флешку и укажите кнопкой «SQL база»; так можно экспортировать чаты даже на старых Windows, где сами AutoClaw/ZCode не запускаются.

## Установка и запуск

Релизы для Windows можно скачать тут: <https://github.com/vadimrm/Z.ai-ChatsExporter/releases>

Готовая сборка не требует Python: скачайте `Z.ai-ChatsExporter-…-win64.zip` из последнего релиза (внутри — `ExportChat.exe`, заводской `db_profiles.cfg` и краткая инструкция), распакуйте и запустите двойным кликом.

Настройки хранятся в `ExportChat.cfg` рядом с exe (создаётся при первом старте; портативно; реестр и %APPDATA% не используются; UTF-8 с BOM — удобно править и в старом Блокноте). Стандартные имена и все стандартные пути обеих баз — в отдельном человеко-редактируемом **db_profiles.cfg** (лежит в поставке рядом с exe; со справкой, для каких версий AutoClaw/ZCode пути проверены): программа читает его при старте и никогда не перезаписывает — если приложение сменит место базы, просто исправьте пути текстом, exe менять не нужно. Если файл удалить или испортить — программа сообщит об этом, испорченный сохранится как `db_profiles.cfg.err`, а на его место будет записан заводской.

Из исходников (Python 3.10+):

```bat
python frontend\main.py
```

Пересборка exe — `build\build.bat` (PyInstaller). Архитектура и план работ: `GUI_PLAN.md`; анализ вариантов: `GUI_VARIANTS.md`; журнал изменений: `AGREEMENTS.md`.

## Интерфейс (кратко)

- «Папка экспорта» + поле пути — материнская папка вывода (по умолчанию — папка exe); чаты пишутся в субпапки «AutoClaw Chats» / «ZCode Chats», копии баз (кнопка «Экспорт SQL базы») — в «AutoClaw SQL» / «ZCode SQL»;
- «SQL база» — выбрать файл базы: список чатов грузится сразу; «Обновить чаты» перечитывает; авто-поиск проверяет только стандартные места из `db_profiles.cfg` — без реестра и без скана диска;
- «Открыть папку экспорта» — проводник (после экспорта — с выделением последнего файла);
- тексты статус-строки и заголовок окна копируются: Ctrl+C в окне или правый клик по статусу; окно «Ошибки экспорта» — с кнопкой «Копировать»;
- повторный запуск не создаёт копию: существующее окно выводится на передний план;
- «Donate» и кнопка авторского сайта — <https://www.vmgames.com/>.

## Файлы в экспорте

- **Вложенные** — берутся из блока `Attached workspace files` в тексте запроса: имя, тип, размер. Сам блок из текста убирается (AutoClaw).
- **Созданные** — из таблицы `governed_tool_artifacts`, привязка по `tool_call_id`, поэтому файл попадает в тот ход, где он появился (AutoClaw).
- **«Готово к скачиванию»** — то, что агент отдал через `deliver_file` (AutoClaw).
- **«Показать служебные файлы»** — дополнительно показывает всё, что создавалось по ходу: скрипты, черновики, патчи (AutoClaw).
- Вложения ZCode — из `file`-частей сообщения: имя, путь, MIME.

Имена файлов выводятся в кавычках, служебные директивы вида `:zwork-file-citation{...}` в текст не попадают.

## Форматы

| Формат | Что внутри |
| --- | --- |
| `md` | Разметка сохраняется как есть: заголовки, списки, таблицы, код |
| `txt` | Разметка разбирается в чистый текст: без `**`, обратных кавычек, `#`, табличных `\|`; списки становятся `•`, ссылки — `текст (адрес)` |
| `json` | Структура: `session` + `turns[]`, в каждом ходе `request`, `attachments`, `answers`, `tools`, `narration` |

BOM (три байта `EF BB BF`) по умолчанию пишется в `.md` и `.txt` (чекбокс «UTF-8 Byte Order Mark» в матрице, отдельно для каждого формата). В JSON-файлы BOM не добавляется никогда — строгие парсеры его не принимают.

## Как это работает

AutoClaw — `%APPDATA%\AutoClaw*\accounts\<id>\runtime\runtime.sqlite`, таблицы:

- `work_sessions` — список диалогов;
- `neutral_session_entries` — сообщения (запросы, ответы, вызовы инструментов);
- `governed_tool_artifacts` — созданные файлы.

ZCode — `~/.zcode/cli/db/db.sqlite`, таблицы `session` / `message` / `part`; сабагентские сессии отфильтровываются, при блокировке базы приложением читается временная копия.

Соединение открывается в режиме `mode=ro`, никаких записей в базу нет. Адаптеры — `backend/adapter.py` (`AutoClawAdapter`, `ZCodeAdapter`); места баз — `frontend/db_profiles.py` + файл `db_profiles.cfg` рядом с exe.

## Ограничения

- Схема баз внутренняя и недокументированная: обновление AutoClaw/ZCode может её изменить. При поломке программа сообщит, в чём дело, а не испортит данные; места баз правятся в db_profiles.cfg без пересборки.
- В `txt` теряется форматирование — это его назначение.
- С включёнными вызовами инструментов файл растёт быстро: в одном ходе бывает 60+ вызовов.
- Картинки и бинарники не выгружаются — только имена, типы и размеры.
- Инструмент не связан с Z.ai; это не официальный экспорт.

## Если что-то не работает

Скопируйте текст ошибки (Ctrl+C в окне, либо кнопка «Копировать» в окне «Ошибки экспорта») и пришлите автору — без точного текста причину не найти.
