# Z.ai Chats Exporter by Vadim R.M. ver. 2.00

Экспорт локальных чатов **AutoClaw** и **ZCode (Z.ai)** в Markdown, TXT и JSON — включая **удалённые и скрытые** диалоги.

Настольная программа для Windows: читает локальные базы чатов AutoClaw и ZCode и сохраняет переписку в файлы. Один exe, Python устанавливать не нужно. Программа работает только с **локальными копиями** баз — закрывать AutoClaw/ZCode не требуется, исходные базы открываются только на чтение.

Неофициальный инструмент. Не связан с Z.ai, в сеть не ходит.

## Возможности

- два режима — **Zcode Chats** (db.sqlite) и **AutoClaw Chats** (runtime.sqlite); первый запуск открывается в Zcode Chats;
- таблица диалогов: ☑-выбор, сортировка по любому столбцу, поиск, колонки «Проект», «Тип», «Число», «Ток» (размер контекста), даты;
- **скрытые и удалённые чаты**: чекбокс «Показывать скрытые чаты» открывает диалоги с пометками `del` (удалённые), `arch` (архивные), `wfchld`, `selchat`, `auto` — см. раздел «Удалённые чаты» ниже;
- экспорт выбранных чатов × форматов MD / TXT / JSON (N×M файлов за прогон) или всё в один файл;
- подробная шапка каждого экспорта: проект, тип, сессия, даты, «Сообщений: N / M (вопросы/ответы)», файлы, модели, **токены контекста с долей от окна модели** («Контекст чата: 28 019 токенов (2.8%/1М)»), автосжатие, суммарный расход токенов;
- блоки файлов в экспорте показываются всегда: вложения пользователя и «Готово к скачиванию» (доставленные агентом файлы); для AutoClaw есть опция «Показать служебные файлы» (скрипты и черновики, создававшиеся по ходу работы);
- вызовы инструментов и промежуточные реплики — по чекбоксам, с лимитом длины; пресет «Только актуальный контекст» — экспорт того, что модель реально видит после автосжатия (сводка уплотнённой истории + живой хвост);
- безопасный импорт баз: локальная копия обновляется через SQLite backup-API (работает при запущенных AutoClaw/ZCode), перед заменой проверяется и сохраняются **три предыдущие версии** (ZCodeData / AutoClawData рядом с exe);
- все тексты программы копируются: собственные диалоги с выделяемым текстом, правый клик в любом месте GUI (поля, строки и заголовок таблицы, статус-строка, заголовок окна);
- язык интерфейса и экспортов: русский, английский, китайский; все строки — в редактируемых `lang_*.cfg` рядом с exe;
- полностью портативно: без установки, без реестра и %APPDATA%; иконка — «гусиное перо».

## Удалённые чаты и восстановление

Экспортёр показывает даже **удалённые** чаты: пока локальная копия базы не обновлена, диалог в ней ещё жив.

> **Случайно удалили чат?** Не закрывайте ZCode (AutoClaw). Запустите экспортёр и поищите чат по названию — скорее всего, он ещё есть в нетронутом виде в вашей локальной копии базы. Если его там нет — обновите локальную SQL-базу кнопкой «Обновить SQL базу», включите «Показывать скрытые чаты» и поищите диалог с пометкой `del`.
>
> **Общая рекомендация:** обновляйте локальную SQL-базу в конце рабочего дня. Экспортёр хранит три предыдущие версии базы в папках `ZCodeData` (`AutoClawData`) рядом с `ExportChat.exe`, поэтому случайно удалённый накануне чат можно вернуть из вчерашней копии (`.bak1`–`.bak3`).

## Требования

- Windows 8.1 или новее, 64-бит (проверено на 8.1, 10 и 11);
- Python, AutoClaw и ZCode на этой машине не обязательны: базы — обычные файлы, их можно принести на флешке и указать кнопкой «Путь к SQL базе».

## Установка и запуск

Скачайте `ExportChat.exe` из папки [release](release/) (или из [Releases](https://github.com/vadimrm/Z.ai-ChatsExporter/releases)), положите рядом `db_profiles.cfg` и `lang_*.cfg` из той же папки — и запускайте двойным кликом. Настройки (`ExportChat.cfg`) создаются рядом с exe при первом старте.

Из исходников (Python 3.10+): `python frontend\main.py`. Пересборка exe — `src\build\build.bat` (PyInstaller).

Подробное описание всех элементов интерфейса — в [MANUAL.ru.md](MANUAL.ru.md); изменения по сравнению с версией 1.27 — в [CHANGES.ru.md](CHANGES.ru.md).

## Форматы

| Формат | Что внутри |
| --- | --- |
| `md` | Разметка сохраняется как есть: заголовки, списки, таблицы, код |
| `txt` | Чистый текст: разметка убирается, списки становятся `•`, ссылки — «текст (адрес)» |
| `json` | Структура: `session` (шапка) + `turns[]` с запросами, ответами, вложениями, инструментами |

Имена файлов: `AC-дата-название.ext` / `ZC-дата-название.ext`, повторный экспорт не перезаписывает (суффикс ` (1)`, ` (2)`…). BOM в `.md`/`.txt` — по чекбоксу (по умолчанию включён), в JSON — никогда.

## Как это работает

Программа читает **локальные копии** баз: AutoClaw — `%APPDATA%\AutoClaw*\accounts\<id>\runtime\runtime.sqlite`, ZCode — `~/.zcode/cli/db/db.sqlite` (+ `tasks-index.sqlite`). Копия создаётся/обновляется по кнопке «Обновить SQL базу» через backup-API SQLite — целостно даже при работающих AutoClaw/ZCode; исходные базы программа никогда не меняет. Пути к базам задаются в человеко-редактируемом `db_profiles.cfg` (v3) рядом с exe — при смене места хранения достаточно поправить его текстом, exe пересобирать не нужно.

## Структура репозитория

- `release/` — готовая поставка: `ExportChat.exe`, `db_profiles.cfg`, `lang_*.cfg`, краткая инструкция;
- `src/` — исходники (backend — движки экспорта, frontend — GUI и тесты, build — сборка);
- `screenshots/` — скриншоты;
- `docs/dev/` — исторические проектные документы.

## Ограничения

- Схема баз внутренняя и недокументированная: обновление AutoClaw/ZCode может её изменить (тогда программа честно сообщит об ошибке и не тронет данные).
- Картинки и бинарные вложения не выгружаются — только имена, типы и размеры.
- С включёнными вызовами инструментов файл растёт быстро.
