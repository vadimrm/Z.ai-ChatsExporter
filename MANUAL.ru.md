# Z.ai Chats Exporter — подробное описание интерфейса (ver. 2.00)

Русский · [English](MANUAL.md) · [中文](MANUAL.zh.md)

Дополнение к [README.ru.md](README.ru.md): все элементы окна, статусы, конфигурационные файлы и особенности их работы. Код программы не меняется этим документом — при расхождениях верьте программе.

![Интерфейс программы](screenshots/ZAICHEXP-ver-2.00.png)

## 1. Общие сведения

- Один exe (`ExportChat.exe`), полностью портативно: настройки, языковые файлы и локальные копии баз лежат рядом с exe; реестр и %APPDATA% не используются.
- Исходные базы AutoClaw/ZCode не изменяются никогда: программа работает с собственными копиями (SQLite backup-API, чтение в `mode=ro`).
- Повторный запуск не создаёт второе окно: существующее выводится на передний план.
- Минимальная система: Windows 8.1 (64-бит).

## 2. Заголовок окна

«Z.ai Chats Exporter by Vadim R.M. ver. N.NN — экспорт диалогов AutoClaw и ZCode». Иконка — «гусиное перо» (иконка exe совпадает с оконной). Правый клик по пустому месту окна копирует заголовок целиком.

## 3. Режимы и список чатов

- Радиокнопки **Zcode Chats** / **AutoClaw Chats** (Zcode — слева; первый запуск открывается в нём; далее программа запоминает последний режим). Смена режима переключает список, путь базы и видимость строк матрицы опций.
- Чекбокс **«Показывать скрытые чаты»** — открывает диалоги, скрытые по умолчанию. Колонка «Тип» показывает причину: `del` — удалённый, `arch` — архивный, `wfchld` — дочерняя сессия workflow-агента, `selchat` — копия контекста (side-chat), `auto` — служебный диалог; пусто («—») — обычный видимый чат.
- **Поиск** — фильтр по названию чата (без учёта регистра).
- Таблица: колонки ☑, «Проект», «Чат», «Тип», «Число» (запросов/ответов), «Ток» (размер контекста последнего запроса), «Обновлён», «Создан». Клик по заголовку — сортировка по возрастанию/убыванию. ☑ по умолчанию стоит у первого чата.
- **Правый клик по строке** — меню «Копировать текст: …» копирует строку **под курсором** (все колонки через « | »), независимо от синего выделения.
- **Правый клик по заголовку таблицы** — два пункта: копировать заголовки всех колонок и «Копировать заголовок и список чатов» (шапка колонок + все чаты, выведенные текущим фильтром; скрытые не включаются).

## 4. Базы: путь, локальная копия, обновление

- Поле **«Путь к SQL базе»** + кнопка: указать файл-мастер (`runtime.sqlite` для AutoClaw, `db.sqlite` для ZCode). Диалог открывается в осмысленной папке: путь из конфига существует — его папка; нет — папка exe.
- Программа работает с **локальной копией** мастера (ZCodeData / AutoClawData рядом с exe). Если копии нет — при старте спросит «Отсутствует копия данных, импортировать?» и скопирует мастер; если мастера нет — честный статус с подсказкой.
- Кнопка **«Обновить SQL базу»** — безопасный импорт: мастер копируется во временный файл, проверяется по таблицам, затем старая копия убирается в бэкапы (`.bak1`–`.bak3`, все три предыдущие версии), новая встаёт на место. При сбое — откат к `.bak1`; мусорный файл локальные копии не трогает.
- Копирование идёт через SQLite backup-API — **закрывать AutoClaw/ZCode не нужно**. Случай «мастер = локальная копия» отклоняется статусом (раньше мог повредить базу).
- Для ZCode копируется и вторая база `tasks-index.sqlite` (нужна для имён проектов); если она не найдена по конфигу — сначала ищется рядом с мастером, при неудаче импорт «минимальный» и появляется жёлтая нота о неполном функционале.
- Статусы импорта: зелёный «Копия импортирована», жёлтый «минимальный состав…», красный при ошибках.

## 5. Папка экспорта

- Поле **«Папка экспорта»** + «Обзор…» — материнская папка; чаты пишутся в субпапки «ZCode Chats» / «AutoClaw Chats», внутри — по папкам проектов (ZCode).
- Кнопка **«Открыть папку экспорта»** открывает папку в проводнике, после экспорта — с выделением последнего файла. Если путь не существует (или это файл) — красный статус **«Некорректная папка экспорта»**; после выбора правильной папки через «Обзор…» ошибка снимается.
- Файлы никогда не перезаписываются: повторный экспорт того же чата даёт суффикс ` (1)`, ` (2)`…

## 6. Форматы и матрица опций

Чекбоксы **MD / TXT / JSON** — какие форматы производить; матрица опций настраивает каждый формат отдельно:

- **«Добавлять вызов инструментов»** — блоки `🔧 Имя — статус` с JSON-вызовом и результатом; общий для всех форматов лимит **«Максимальная длина, литер»** (обрезает и вызов, и результат).
- **«Промежуточные реплики»** — рассуждения/прогресс-текст ИИ между вызовами инструментов.
- **«Показать служебные файлы»** (только AutoClaw) — блоки «Прочие файлы:» со скриптами и черновиками, создававшимися по ходу (доставленные файлы — блок «Готово к скачиванию:» — показываются всегда, как и вложения пользователя).
- **«UTF-8 Byte Order Mark»** — BOM в `.md`/`.txt` (для старого Блокнота); в JSON ячейка серая — BOM там невозможен.
- **«Только актуальный контекст»** (только ZCode) — срез чата, который модель видит **сейчас**: всё до последнего автосжатия заменяется машинной сводкой («Сводка уплотнённой истории»), остаётся живой хвост; добавляются служебные сообщения, невидимые в GUI, но находящиеся в контексте. В обычном режиме границы автосжатия только помечаются.
- Кнопка-пресет **«Пресет: актуальный контекст модели»** — одним нажатием: актуальный контекст вкл, инструменты вкл, реплики выкл, лимит 10000 (аппаратный потолок ZCode).
- Чекбокс **«записать в один файл»** — все выбранные чаты пакуются в один файл каждого отмеченного формата (имена `AC-ALL-…` / `ZC-ALL-…`); «Выбрать всё» + чекбокс = весь режим в одном файле. Пустые чаты тоже попадают (шапка).

## 7. Статус-строка

- Цвета: зелёный — успех/информация, жёлтый — предупреждение, красный — ошибка. Примеры: «Диалогов: 48 · копия от 23.11.2026 13:08», «Загрузка списка диалогов…», «Готово: N файлов, ошибок M».
- Жёлтые ноты: «db_profiles.cfg не найден/повреждён — записан заводской», «Слишком длинные строки в файле: (имя)» (строки конфигов/языковых файлов длиннее 500 литер обрезаются), «минимальный состав» после импорта без второй базы. Ноты показываются сразу и не всплывают повторно после загрузки списка.
- Текст статуса копируется Ctrl+C или правым кликом; пустой статус — копируется заголовок окна.

## 8. Копирование текста (правый клик)

- **Поля ввода** (путь базы, папка, поиск, лимит): Копировать/Вставить/Вырезать/Выделить всё; без выделения копируется/вырезается **весь текст** поля.
- **Любой элемент GUI** (кнопка, чекбокс, метка): «Копировать текст: …».
- **Строка таблицы** — под кликом; **заголовок таблицы** — все колонки (+ «заголовок и список чатов»); **пустое место окна** — заголовок окна; **статус-строка** — её текст.
- Собственные диалоги (вопросы, предупреждения, ошибки): текст лежит в текстовом поле, выделяется мышью, Ctrl+C, правый клик.

## 9. Языки

Переключатель ru/en/zh меняет интерфейс и язык подписей в экспортируемых файлах. Все строки — в `lang_ru.cfg`, `lang_en.cfg`, `lang_zh.cfg` рядом с exe: правьте текстом, программа перечитывает файл при каждом переключении языка; битый файл — предупреждение, используются встроенные строки. Строки длиннее 500 символов обрезаются с жёлтой нотой.

## 10. Конфигурационные файлы

- **`ExportChat.cfg`** (v7, UTF-8 BOM, JSON) — настройки GUI: язык, папка, пути мастеров, матрица опций, лимит, геометрия окна, режим. Создаётся при первом старте; старые версии (v6 и новее) мигрируют автоматически, чужая структура — файл сохраняется как `.err` и создаётся заводской. В запись конфига экспорт не пишет ничего лишнего.
- **`db_profiles.cfg`** (v3, UTF-8 BOM, JSON с подсказками) — стандартные имена и пути баз, состав файлов каждой базы (относительно главного, включая wal/shm и вторую базу ZCode), пометка `_version`. Человеко-редактируемый: приложение сменило место базы — поправьте текст, exe не трогаем. Отсутствует — создаётся заводской (жёлтая нота); повреждён — `.err` + заводской.
- **`lang_*.cfg`** — см. раздел 9.

## 11. Экспортированные файлы

- Имена: `AC-ГГГГ-ММ-ДД название.ext` / `ZC-ГГГГ-ММ-ДД название.ext`.
- **Шапка** (md/txt/json): «Харнесс-ядро: ZCode 0.17.1» (версия встроенного ядра ZCode, а не приложения) или «Харнесс: AutoClaw»; Проект; Чат; Тип; Сессия; Каталог (ZCode); Создана/Обновлена; **Сообщений: N / M (вопросы/ответы)**; Файлы (вложено/готово к скачиванию); Модели (с effort у ZCode); **Контекст чата: 28 019 токенов (2.8%/1М)** — у AutoClaw «16 161 из 1М (1.5%)» + «Автосжатие при: 812 К (77%)»; Всего израсходовано; Экспорт; строка экспортёра (в txt — в рамке из чёрточек, и в конце каждого чата — футер).
- **Тело**: ходы «### N. Вы — дата» → текст запроса → «📎 Вложено:» (всегда) → инструменты → ответы с автором («GLM-5.3 Max — дата (3 мин 58 сек)»); у AutoClaw после ответов — «📄 Готово к скачиванию:» и, при включённой опции, «Прочие файлы:».
- **TXT**: разметка разбирается в текст, код — в блоки «python { … }», черта «-»×длина под заголовками.
- **JSON**: `session` (та же шапка) + `turns[]` с `request/attachments/answers/tools/narration`.

## 12. Удалённые чаты: практические сценарии

1. **Только что удалили чат, программы ещё открыты** — запустите экспортёр, не закрывая ZCode/AutoClaw: локальная копия базы ещё содержит чат «живым», он виден в списке как обычный.
2. **Копия уже обновлена, чат исчез** — включите «Показывать скрытые чаты»: в базе чат обычно остаётся с меткой удаления и виден с типом `del`; экспортируется как обычный.
3. **Удаление было давно, копия обновлялась много раз** — шансов меньше: откройте папку `ZCodeData` (`AutoClawData`) рядом с exe, там лежат три предыдущие версии базы (`.bak1` — самая свежая из старых). Закройте экспортёр, переименуйте текущую `db.sqlite` (`runtime.sqlite`), верните ей имя из `.bak1` — и чат снова в списке (скрытый, `del`). Поэтому полезно обновлять копию в конце рабочего дня: три ночи подряд бэкапов у вас в кармане.

## 13. Известные особенности

- Схемы баз внутренние: после крупного обновления AutoClaw/ZCode программа может сообщить о неизвестной структуре — она не портит данные, конфиги правятся текстом.
- Колонка «Ток» у ZCode — размер последнего запроса (весь контекст), у AutoClaw — контекст последнего завершённого хода.
- Доля контекста (X%/1М) выводится для известных моделей (GLM-5.3 / GLM-5.3-Flash); для прочих — только число токенов.
- Экспорт «в один файл» с включёнными инструментами может быть очень большим.
- Имена проектов ZCode берутся из `tasks-index.sqlite`; без неё чаты группируются без имён.
